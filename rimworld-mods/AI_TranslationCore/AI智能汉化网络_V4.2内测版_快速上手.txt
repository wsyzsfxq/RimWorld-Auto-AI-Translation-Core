AI 智能汉化网络 V4.2 内测版
快速上手与常见问题
========================================

一、适用范围

本内测包用于 RimWorld 1.6。
内测版仍可能存在界面、兼容性或数据迁移问题。安装前建议备份现有译文；不要同时启用多个 AI 智能汉化网络版本。


二、安装

1. 退出 RimWorld。
2. 解压压缩包，将完整的“AI_TranslationCore”文件夹放入 RimWorld\Mods\。
3. 如果已经安装旧版，请停用或移走旧版，避免重复加载。
4. 在游戏 Mod 列表中启用“AI 智能汉化网络”，然后重新启动游戏。


三、第一次使用

1. 打开“AI 智能汉化网络”，进入【设置】。
2. 在“AI 接口”区域填写供应商、Base URL（使用预设时可留空）、API Key 和模型。
3. 点击右侧勾／叉图标启用该 API；绿色勾表示启用，红色叉表示停用。
4. 按需要选择结构化输出、任务用量分级和单次最大输出 Token。
5. 点击【测试连线】。多个 API 会作为独立接口轮询使用。

提示：API Key 属于敏感凭据，请勿在截图、日志反馈或公开文件中展示。


四、推荐使用顺序

（一）先检查云端译文

1. 进入【云端翻译】，选择目标语言。
2. 选择下载范围：【已启用 Mod】或【全部已安装】。
3. 点击【刷新云端列表】。
4. 优先使用【一键下载最佳可用译文】。云端选择顺序为：汉化组精翻 > 人工精翻 > AI 译文；同类取最新版本。
5. 下载前请阅读确认窗口。云端文件会替换 ATC 生成包中的现有本地译文；已保存到数据库的手动译文会重新恢复，但尚未点击【刷新状态】同步的外部 XML 修改可能被覆盖。

【管理下载排除列表】中的“是否排除”：
- 否：允许该 Mod 参与云端下载。
- 是（红色）：跳过该 Mod 的云端下载。


（二）云端没有合适译文时使用翻译工作台

1. 进入【翻译工作台】，选择要处理的 Mod。
2. 首次使用或外部修改过 XML 后，先点击【刷新状态】。
3. 可先点击【试跑】估算 Token。试跑不发送真实模型请求，也不写入正式译文。
4. 五个主要操作的区别：
   - 【分析】：补齐 XML／DLL 本地分析结果，不调用 AI 翻译。
   - 【AI 复核】：只判断待判定条目是否需要翻译，不生成译文。
   - 【AI 翻译】：只翻译当前有效分类为“需要翻译”的条目。
   - 【一键翻译】：按“分析 → AI 复核 → AI 翻译”顺序执行。
   - 【停止】：请求停止当前后台任务；等待队列和在途请求排空后才完全停止。
5. DLL 界面文字是否参与分析，由【设置 → 高级兼容模式】中的“应用已保存的 DLL UI 译文”等相关选项控制。


（三）检查和修改译文

1. 进入【译文编辑】，在左侧选择 Mod。
2. 使用“分类”和“译文”下拉筛选条目；页码与翻页按钮位于列表底部。
3. 选择条目后，可以查看本地分析、AI 复核和手动分类三层结果。
4. “手动”下拉可设为【需要翻译】【待复核】【无需翻译】或【未设置（跟随自动结果）】。
5. 在右侧编辑译文后点击【保存译文】；不需要该手动译文时点击【删除译文】。

优先级：手动译文 > 第三方人工译文 > Mod 原生译文 > 云端译文 > 本地 AI 译文。


五、任务、日志与维护

- 展开【任务／日志】可查看任务详情、运行日志和错误日志。
- 反馈问题时优先提供错误发生时间、Mod 名称、操作步骤、运行日志和错误日志；截图前请遮住 API Key。
- 【清除结果…】和【清理过期数据…】属于不可恢复或可能影响历史记录的操作，请先看清确认窗口中的范围。
- 外部手工修改翻译 XML 后，应先回到工作台点击【刷新状态】，再继续云端下载或 AI 翻译。


六、常见问题

Q：按钮为什么是灰色的？
A：通常是没有选择 Mod、后台任务正在运行、尚未完成状态同步，或没有可用且已启用的 API。先查看按钮提示和任务／错误日志。

Q：【试跑】会消耗 API 额度吗？
A：不会。试跑只计算范围和 Token 预估，不发送真实模型请求，也不保存正式译文。

Q：【AI 复核】为什么执行后没有译文？
A：AI 复核只负责分类，确定条目是否需要翻译。生成译文需要继续执行【AI 翻译】或【一键翻译】。

Q：为什么云端下载后自己的修改不见了？
A：云端下载会替换 ATC 生成包中的对应文件。通过译文编辑器保存并已进入数据库的手动译文会恢复；直接修改 XML 但尚未【刷新状态】的内容可能被覆盖。

Q：保存后目标 Mod 的界面没有变化怎么办？
A：先关闭并重新打开目标界面。DLL 硬编码界面还需确认高级兼容模式相关功能已启用；必要时重新启动游戏。

Q：怎样反馈内测问题？
A：请提供 RimWorld 版本、Mod 名称、复现步骤、大致时间、完整界面截图、运行日志和错误日志。不要发送未遮挡的 API Key。
