# 源码交付与编译产物

状态：2026-11-06 用户明确重申，适用于个人远端及原作者 PR。

- Git 提交和推送仅包含源码、资源和文档。所有远端均不得新增或更新 DLL、EXE、PDB、SO、DYLIB 等编译产物，不存在“个人分支可以提交 DLL”的例外。
- 构建输出、运行依赖、本地 Mod 包及测试部署文件可以在本机保留和使用，但不能因此进入提交。不得使用强制添加绕过忽略规则提交编译产物。
- 目录中的既有已跟踪二进制不会因忽略规则自动解除跟踪；每次提交仍须检查编译产物路径的差异，不能混入新的或更新的编译文件。
- 原作者 PR 保留其既有二进制基线，源码交付不携带本地构建结果。
- 发现本轮误加的编译产物时，从本轮提交中剔除，保留本地文件；不以再补一个删除提交代替清除本轮误提交。远端若已更新，先确认分支头，仅纠正本轮自己的提交，不能覆盖他人更新。
- 清理更早历史或取消跟踪旧版本文件属于另行处理的范围，不因一次普通提交请求擅自重写全仓库历史。
