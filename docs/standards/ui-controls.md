# 界面控件样式

状态：2026-11-04 用户确认的下拉和紧凑开关基准；源码已接线，画面未经运行验收。

适用范围：设置、翻译工作台、译文编辑器、云端页面及本项目自己的弹窗。该标准只统一外观与交互表达，不改变数据、模式、权限或任务规则。

| 控件用途 | 统一方式 |
|---|---|
| 选择一个值或范围 | 名称放框外左侧，右侧蓝灰框显示当前值和下拉箭头；使用 `WorkflowUiStyle.LabeledDropdown`。已有表单分别画标签和框时，选择框仍用 `Dropdown` 样式 |
| 紧凑开关 | 使用 `ToggleButton`，边框、绿勾／红叉及灰色禁用状态统一；宽度用 `ToggleButtonWidth` 按实际文字、标记和边距计算 |
| 普通动作 | 使用 `Button` 的 `Quiet`，例如关闭、刷新、打开目录；不使用下拉样式伪装动作 |
| 主要执行或保存 | 使用 `Primary`，例如一键翻译、上传、保存 |
| 需要提醒的操作 | 使用 `Warning`，例如重新加载、恢复默认；含义与文字一起表达 |
| 删除、清除或停止 | 使用 `Stop`；不因颜色改变确认、取消或任务语义 |
| 多选清单、确认清单 | 保留复选框；不能改成一次只选一个的菜单或不可识别的动作按钮 |
| 单选选项、分页 | 当前选择必须有明确选中状态；上传标记仍是互斥选项，不冒充下拉，也不因再次点击而变为全不选 |

## 文字与尺寸

- 按钮名用短而直接的词。功能补充、完整长值和限制放在悬浮提示中。
- 按钮内文字保持单行、垂直居中；紧凑框不继承前面标签的换行、内边距或文字偏移。
- 普通设置使用 Small 字体。表格内、密集工具栏可明确使用 Tiny，但不能依靠上一处绘制遗留的字体状态。
- 一行的高度须能容纳所选字体及图标。当前工作台选项行为 34，不能再将四个汉字和标记塞进七分之一列的一半。
- 使用局部样式副本，不改游戏共享样式。文字测量和绘制使用同一样式；完成后恢复字体、对齐、换行及颜色状态。
- 长值不能通过自动换行挤出按钮；布局先分配足够宽度，必要时缩短显示值并提供完整提示。例如云端版本框只显示版本号，来源和合并信息仍在提示及选项中。
- 与下方动作对应的选项应当使用该动作的同一列边界；复核范围整组只能占“AI 复核”正上方的一列。长范围值用“已选2类／全部”等摘要及完整提示，不得横向借用其它动作列。
- 只改文字纵坐标几像素不算解决宽度不足；不能用禁止整个游戏换行修补本项目的按钮。

## 禁用与行为

- 共享按钮同时尊重传入的可用条件及外层 `GUI.enabled`，禁用时不响应点击、不显示可交互悬停高亮，文字或标记显示为灰色。
- 禁用原因由调用处提供，例如“未配置大模型”“UI 拦截模式不适用”。
- 原有模型检查、保存、取消、上传来源校验和全局任务互斥继续生效；外观统一不能删去这些判断。

## 范围边界

此次没有重排所有窄屏表单。有效逻辑窗口较窄时，AI 配置卡片的两列布局仍需单独设计上下排列；也没有把所有原生表单复选框改成紧凑开关。后续改动应先确认用途，再复用相应控件，不把不同用途强制做成一种外观。
