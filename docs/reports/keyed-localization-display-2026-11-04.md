## 改了什么

1. 分析前在游戏主线程复制官方默认语言的 Keyed 目录。按真实来源路径对应 Mod，后台分析只读取快照。核心、DLC、Harmony 等原有排除项不变。
2. 用这份目录补齐所选 Mod 的 XML 候选。原有 Keyed 身份仍是“Mod + XML + Keyed + key”，不另建一套候选或模型请求。
3. 官方明确声明的自然语言条目直接进入“需要翻译”。在此窄范围内，人工分类仍然最高；旧 AI 的“无需翻译”不能压过官方本地化声明。AI 建议仍保存在原记录中。C# 裁决、SQL 汇总和分页、编辑器即时显示使用相同规则。
4. XML 分析版本从 `xml-3.01` 调整为 `xml-3.02`，输入指纹也包含官方目录内容。旧成功结果会重新分析，新理由不会永远被旧缓存跳过。条目 ID 和原文哈希规则不变，已有有效译文继续保留。
5. 在官方 `Translator.Translate` 返回时记录实际字符串对象对应的翻译键。第三方字段即使继续保存这份旧字符串，显示时也能按键重新取当前译文；不写入第三方字段、不重跑静态初始化。
6. 对钩子安装前就已缓存的英文或“泰南语”，用官方原文目录及本机实际伪翻译字符映射补来源。相同文字对应不同译文时，先用实际字符串来源，再结合显示调用所属 Mod；无法消歧时保留原值。
7. 绘制和测量入口一起使用新文字。旧 UI 模式仍从自己的缓存取硬编码译文；已确认属于 Keyed 的伪译不会再次作为新原文排进旧 UI 模型队列。

**目录补全针对全部可归属的已声明 Keyed，不只读取 `activeLanguage` 当前缺少的键。** ATC 的目标语种可以与游戏语言不同，不能把游戏当前语言的缺键结果当作另一语种的权威状态。是否需要请求 AI，仍由目标语言、原文哈希和当前有效译文判断；目录里出现一个键不等于再次收费翻译。快照中的 `Missing` 是官方判断证据，不取代这些检查。

## ASF / ASGS 的链路

截图中的文字都是 Keyed XML，既有简体文件及数据库已保存中文。ASF 的反射批量初始化、ASGS 的逐字段初始化最终都保存普通字符串，旧值不会随着 XML 文件更新自行变化。

本次桥接在 `Widgets`、`GUI` 的文字绘制、`Text` / `GenUI` / `GUIStyle` 的测量和 Tooltip 显示边界重新按原键取当前译文，供两种模式共用。原字段和内部逻辑不变。因此，这些已有译文的文字不需要再次向模型请求。

静态读取当前 ASGS 文件发现，`ASGS_CatalogOptions` 和 `ASGS_Text_ModSettings` 原文相同，当前译文也都是“Mod 设置”，可以得到一致显示值。若用户以后为同一个 Mod 的同文键填写不同译文，真实对象来源可区分；只有旧副本且无法定位具体键时不会猜选其一，并记录一次调试信息。

数字位置参数和普通命名参数按官方模板匹配、恢复到当前译文模板；保留已经格式化好的参数值，不把每个数量变化当成新原文。转义花括号也按模板文字处理。不会对参数本身发起额外翻译。

## 姓名折行

本机 1.7 实际 IL 表明：殖民者栏调用 `GenMapUI.DrawPawnLabel`；地图标签也走同一链。该链先通过 `GetPawnLabelNameWidth` 测宽，随后才调用 `Widgets.Label`。旧拦截原先只在最后一步换中文，可能按短英文名建框，再画更宽的中文名。

新增处理在 `GenMapUI.GetPawnLabel` 截断名称前读取同一份已缓存译文，并以译文作为截断和宽度缓存的键。其它测量入口也读取缓存，不触发采集或模型请求。没有删除换行、禁止全部 UI 换行、扩大所有标签框，或关闭姓名翻译；不修改角色本身的姓名。

用户已经确认“Irina → 伊琳娜”的缓存是正常单行文字，本次未将问题归咎于译文含换行。1.6 与 1.7 均已静态确认对应 `GetPawnLabel` 签名存在。

## 真实边界

- 还不能声称运行后所有 Mod 都已没有“泰南语”；本次没有运行验收。
- 完整旧字符串、普通数字/命名参数模板有读取路径。复杂语法条件表达式、任意拼接/裁剪后的旧文本、同一个 Mod 内无法区分的多个同文键，可能仍无法安全反查；不会以错误译文掩盖未覆盖。
- 未调用官方本地化接口的裸硬编码，仍走现有 DLL / UI 逻辑。ASGS 原有 9 条 DLL 清单显示参数覆盖不足不因这次 XML 桥接就被宣布解决。
- 官方目录无法关联来源 Mod 的虚拟或动态键，不会被随意归到另一个 Mod 并消费 Token。
- 纯标点、数字、仅格式占位内容没有可变音的字母，保持原有规则，不额外请求模型。本次没有伪造其“Mod 原生”或“AI 翻译”来源，也未新增独立的原样输出来源类别。
- 原有静态刷新器只处理少量可写、带特定启动标记的字段，明确跳过只读字段；本次没有扩大它的反射写入范围。

后续人工验收应分别查看 ASF / ASGS 设置页、参数变化、两个同文键使用不同译文的情形，以及殖民者栏和地图姓名。产物能编译或复制成功不能替代这些验收。
