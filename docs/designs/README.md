## 1. 文档状态

| 状态 | 含义 |
|---|---|
| 当前基准 | 已由产品讨论确认，是对应范围内实施与重构的首要依据 |
| 专项基准 | 对某个独立子系统仍然有效，但不得覆盖更高优先级的当前基准 |
| 部分有效 | 仍包含可复用设计，但部分章节已被新文档取代 |
| 历史背景 | 用于解释既有代码和约束，不直接定义新功能 |
| 草案 | 尚有关键决策未确认，不得作为最终产品约束 |
| 已废弃 | 不再用于实施，只保留历史记录 |

## 3. 文档覆盖关系

当文档内容冲突时，按以下规则处理：

1. 范围更具体且状态为“当前基准”的文档优先。
2. 同一范围内，文档明确写出的“取代/废弃”关系优先。
3. 仍无法判断时，以最近一次由用户确认并登记到本索引的决策为准。
4. 当前代码行为不自动等于当前产品设计；重构时必须区分“现状”和“目标”。

当前已确认的覆盖关系：

- `ATC-DES-003` 的 2026-11-04 补充将新配置的默认模式改为 UI 拦截模式，已有用户保存的模式选择继续生效；该模式下工作台只处理 XML，DLL 数据和开关偏好保留，切回后恢复使用。取代此前默认 DLL 模式及 UI 模式可显式执行 DLL 工作流的安排。

- `ATC-DES-003` 的 2026-10-30 补充恢复可切换的旧 UI 拦截模式，替代“UI 拦截只能采集”的统一限制。旧模式使用独立 JSON 缓存，暂停新版采集和 DLL 译文应用，不进入 SQLite 工作流；2026-11-04 补充将该模式下的工作台限定为 XML，替代此前仍可显式执行 DLL 工作流的安排。DLL 开关偏好和历史数据保留，切回 DLL 分析模式后恢复。源码已修改，未经编译或运行验证；本次界面及后台范围见 [UI 模式工作台修改](../reports/ui-mode-workbench-2026-11-04.md)。

- `ATC-DES-003` 的 2026-10-08 补充确认原生译文读取失败允许一键流程继续 AI，取代此前中止要求；同时补齐 XML/DLL 目标语种记录、原生译文落盘、上传预览人工保存与 Tooltip 来源定位。见 [静态审阅与修复记录](../reports/current-changes-static-review-2026-10-08.md)。

- `ATC-DES-003` 的 2026-10-07 补充授权实施手工参考字典、官方内置种子和按批次提供语境参考，取代此前字典暂缓范围；不包含自动词库学习或批量替换。

- `ATC-DES-003` 的 2026-10-06 补充确认首次页面 Mod 名录同步、XML/DLL 触发的全体已加载 Mod 原生译文收集，以及按语种和条目键识别已有译文；实施情况见 `ATC-IMP-001` 同日记录。

- `ATC-DES-003` 细化 `ATC-DES-001` 的内部步骤职责、独立入口、单一裁决优先级、状态模型和持久化边界，不废弃一键翻译。一键翻译作为显式编排器调用步骤 1、2、4、5，步骤 3 仍是独立的成本预估入口。
- `ATC-DES-001` 的一键翻译方向、DLL 候选召回、静态 IL 分析、编辑器、API 生命周期、错误诊断和术语设计继续有效；其中所有云分析、云端判断缓存、同步云端判断及其服务端协议内容全部废弃。涉及具体步骤输入输出时以 `ATC-DES-003` 为准。
- `ATC-DES-002` 已整体废弃，不得据此实现客户端、服务端、数据库、同步入口或贡献机制。云翻译是另一套独立能力，不受该废弃决定影响。
- `ATC-DES-000` 的安全、兼容性、翻译包输出和热重载约束继续有效，但其中旧的线性翻译流程不再定义新版工作流入口。

## 4. 重构阅读顺序

后续重构当前项目时，按以下顺序阅读：

1. `ATC-DES-003`：先建立工作流步骤、状态和持久化边界。
2. `ATC-DES-000`：确认不能破坏的既有核心能力。
3. `ATC-DES-001`：落实一键编排以及 DLL、API、编辑器和术语实现要求。
4. 对照当前源码制作“保留、迁移、替换、删除”清单；云分析相关旧实现归入删除范围，不能直接把旧流水线改名后继续使用。

## 5. 新增或修改设计文档的登记规则

每份设计文档开头必须至少包含：

```text
文档 ID
状态
最后更新日期
适用范围
取代/依赖关系
尚待确认事项
```

新增设计文档时必须同步完成：

1. 在本索引登记文档 ID、状态、范围和阅读优先级。
2. 在新旧文档中双向注明覆盖或依赖关系。
3. 将未确认事项集中列出，不得混写成已经确认的需求。
4. 决策变化时更新原文和索引，不另建内容重复但关系不明的文档。
5. 实施状态与产品设计状态分开记录；“代码已存在”不等于“产品设计仍有效”。

文档 ID 按 `ATC-DES-xxx` 递增，已有 ID 不得复用或改给其他文档。
